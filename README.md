# 鬼島人生模擬器（Ghost Island Life）

一款純前端、單一 HTML 檔的**台灣味**文字人生模擬遊戲。靈感來自 [yakyulife](https://github.com/LeoGGcat/yakyulife)（棒球生涯模擬器），把「投胎 → 逐年隨機事件 → 死亡 → 結算」的玩法，聚焦在台灣人的一生，並強調**人生階層、故事線的邏輯銜接與養成感**。

## 🎮 立即遊玩

👉 **<https://kai890707.github.io/Life-TW/>**

手機開一個網址就能玩——**專為手機優化的響應式設計**（單欄、直式、大按鈕），也能在電腦瀏覽器玩。純前端、單一 HTML 檔，無需安裝、無任何外部相依；也可直接下載 `index.html` 用瀏覽器開啟。

## ✨ 一眼看懂

- **投胎即命**：只選性別＋出生縣市，其餘（家世、天賦、資質、童年）由**種子**隨機決定；資產一律從 0 開始。
- **7 歲起交給你玩**：逐年隨機事件（370+ 個），隨時可**擲骰養成 8 大專長**、每年一次**主動行動**。
- **雙軌目標**：本局**志向**（達成度影響評級）＋跨局**成就圖鑑**（60+ 項，localStorage 永久記錄）。
- **完整人生系統**：升學→兵役→職涯升遷、投資（股票／房產／創業 IPO）、感情婚姻、生養教育、健康養生、宮廟迷信、8+9 黑道、政治參與、時代大事件…滿滿台灣味與時事梗。
- **結算**：快樂／資產雙曲線、里程碑時間軸、綜合評分 D→SSS、一生收支總結、成就徽章，還能**存成長圖分享（PNG）**。

## 玩法流程

沒有難度選項 —— 你只決定兩件事（性別、出生縣市），其餘全由**種子（命）**隨機決定。

1. **投胎**：取**姓名**、選 **性別** 與 **出生縣市**（＋可自訂／隨機的種子碼；種子會存進網址可分享）。
2. **童年回顧（0–6 歲）**：家世、先天天賦、起始資質、童年際遇全由**種子隨機生成**，你無從選擇 —— 就像現實中你無法選擇原生家庭。個人資產一律從 0 開始。（[為什麼從 7 歲開始？](WIKI.md#設計理念為什麼從-7-歲開始)）
3. **7 歲，開始你的人生**：從此你才有記憶、有選擇。逐年發生 1～3 個事件、隨時可分配技能點，逐年推進或開自動。
4. **結算**：快樂／資產雙曲線圖、人生里程碑時間軸、綜合評分 D→SSS、成就徽章、種子碼，還能**存成長圖分享（PNG）**。
